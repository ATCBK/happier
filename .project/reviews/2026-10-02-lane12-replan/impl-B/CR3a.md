**Owner correction:** make the existing retained review/admission owner consume the exact user's This-time/Skip decision within the original reservation and current reviewed effect. Do not add another queue, automatically trust the Project, or release uncertain native custody. **Required check:** one-slot original Script → This time → one setup and original Script completion; original operation identity retained, no trust mutation, changed digest remains held, cancellation cannot revive it.
