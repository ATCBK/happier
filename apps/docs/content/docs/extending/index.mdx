title: Extending Happier
description: Giving agents more tools, letting them delegate work, and driving Happier itself from somewhere else.

Happier is useful out of the box, but most of its reach comes from what you
connect to it.

## Giving agents more tools

- [MCP servers](/extending/mcp-servers) — browser automation, documentation lookup, internal APIs.
- [Happier tools and actions](/extending/happier-tools) — the actions agents can call inside Happier itself.
- [Prompts and skills](/extending/prompts-and-skills)
- [Registry sources](/extending/registries) — development skill and plugin catalogs, source ownership and fetch requirements.
- [Installables](/extending/installables) — tools Happier can install and keep updated per machine.

## Delegating work

- [Delegated work](/extending/subagents) — subagents, workflows and Claude teams.
- [Agent autonomy](/extending/agent-autonomy) — agents creating and coordinating sessions themselves, and the limits on that.

## Driving Happier from elsewhere

- [SDK and Action API](/extending/sdk) — the source-level Developer Preview for trusted developer tools.
- [Embed sessions in your app](/extending/embed) — the unreleased development contract for a conversation inside a trusted host app.
- [Happier as an MCP server](/extending/happier-as-mcp-server) — running Happier as an external stdio MCP server so an editor or an agent can start and manage sessions.
- [MCP host setup](/extending/mcp-hosts) — wiring that server into a specific editor or automation.
- [Conversation channels](/extending/channels) — connecting external conversations to Sessions, automations or thread routers.
- [Email channel](/extending/email-channel) — connect a mailbox and route authenticated threads to Sessions.
- [Email agent recipes](/extending/email-agent-recipes) — restrict tools, attest MCP identity and schedule a morning brief.
